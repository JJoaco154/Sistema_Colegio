# 🏫 Sistema de Gestión Escolar

Proyecto personal desarrollado en **PHP** para practicar el desarrollo de aplicaciones web y el manejo de información relacionada con una institución educativa.

La idea del proyecto es crear un sistema sencillo que permita trabajar con alumnos, profesores y cursos, utilizando una base de datos para almacenar la información.

Este proyecto fue realizado **por iniciativa propia**, con el objetivo de seguir practicando programación y aplicar conocimientos adquiridos durante mi aprendizaje.

---

## 📌 Sobre el proyecto

El proyecto representa un sistema básico para la gestión de una escuela.

La aplicación trabaja con diferentes entidades relacionadas con una institución educativa, como:

- Alumnos
- Profesores
- Cursos
- Personas

También cuenta con un sistema de conexión a una base de datos y diferentes archivos PHP encargados de manejar la información.

La idea principal fue practicar cómo construir una aplicación utilizando PHP y una base de datos, intentando mantener una estructura sencilla y fácil de entender.

## ✨ Funcionalidades

### 👨‍🎓 Alumnos

El sistema permite trabajar con información relacionada con los alumnos de la institución.

La información de los alumnos puede almacenarse y consultarse desde el sistema.

### 👨‍🏫 Profesores

También se contempla la gestión de profesores, permitiendo trabajar con sus datos dentro de la aplicación.

### 📚 Cursos

El sistema cuenta con una entidad para representar los cursos de la escuela.

Los cursos pueden relacionarse con la información correspondiente a alumnos y profesores.
